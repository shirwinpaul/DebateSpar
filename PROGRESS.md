## Decisions
- Spec file arrived as `PROJECT_SPEC (1).md`; it was copied unchanged to `PROJECT_SPEC.md`.
- Scaffolded by hand (folder name has spaces, so create-next-app won't work). Next.js 16.4, React 19.3, Tailwind 4, Zod 4, Vitest 5, ESLint 9 flat config.
- Models (checked against official docs, Oct 2026): Gemini `gemini-3.8-flash` (lowest thinking level is `LOW`; it can't be turned off), Groq `openai/gpt-oss-120b` (8K TPM, reasoning_effort low). All in `src/config/ai.ts`.
- Theme: CSS variables on `:root` (dark is the default) with a `.light` override; a script runs before paint to apply the saved theme.
- BYOK key is stored in localStorage `dd.geminiKey` and sent in the `x-gemini-key` header.
- Placeholder keys (`PASTE_…`) count as "no key".

- Wizard: `src/components/wizard/*`; settings + current step persist in localStorage (`dd.settings`, `dd.wizardStep`). Pages that read localStorage load client-only (`next/dynamic`, `ssr:false`).
- AI layer: `src/lib/ai/` — `providers.ts` (Gemini SDK, Groq via fetch), `orchestrator.ts` (retry-after ≤10s → 1 retry → Groq; invalid JSON → 1 retry with error appended; TPM-aware trimming; 56s total budget), `prompts.ts` (injection guard, honesty, respect), `tokens.ts` (estimate + compaction), `service.ts` (word caps, fallacy planting), `route.ts` (size limit, per-IP rate limit, Zod, friendly errors), `mock.ts`.
- Request rule: `rounds` holds everything said so far EXCEPT the latest user speech, which goes in `userSpeech`.
- Code picks the fallacy type to plant (random); the call-out is checked against `includedFallacy` in the round JSON.
- AI-opens format: the user's final speech is scored by the judge (`finalUserRoundScore`).
- Overall score formula is in `src/lib/scoring.ts` (documented + tested).
- Arena: `src/components/arena/*`, turn engine `src/lib/engine.ts` (pure, tested). Debate autosaves to `dd.currentDebate`, draft to `dd.draft`. The landing page shows "Resume your debate?" when one exists.
- AI-opens round 1 starts automatically (deferred, ref-guarded so it runs once). After a failed AI call the speech stays in the transcript and a Retry/Continue button resends it.
- Voice/read-aloud: `src/hooks/useSpeech.ts` with feature detection; the voice button is replaced by a "works in Chrome or Edge" note when unsupported.
- Hints: max 2 (`AI_CONFIG.maxHints`); one only counts as used when it succeeds.
- Coach tip comes from `userRoundScore.coachTip` (no extra call). Fallacy call-outs are checked in code (`checkCallout`), one per AI speech.
- Finished debates → `buildRecord` (src/lib/finalize.ts) → history `dd.history` (max 50).
- Charts use one validated colour token `--chart` (#b8860b dark / #8a6300 light, both pass the dataviz validator), with tooltips and a "Show as table" view.
- Report = print stylesheet + `window.print()`; collapsed sections open on `beforeprint`.
- `AGENTS.md` is generated by `next dev` (Next 16). Leave it.
